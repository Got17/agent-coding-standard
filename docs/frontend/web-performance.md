## Web Performance Rules
- Target Core Web Vitals at the 75th percentile on mobile: LCP <= 2.5s, INP <= 200ms, CLS <= 0.1.
- Optimize images using explicit dimensions/aspect ratios and modern formats such as WebP or AVIF to avoid layout shifts.
- Use `fetchpriority="high"` or preload only for likely LCP assets that would otherwise be discovered late.
